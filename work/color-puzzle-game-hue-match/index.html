Color Puzzle Game – Hue Match

A hue-matching puzzle game built around arranging colors into smooth gradients.

Overview

Hue Match is a mobile puzzle game about ordering colors into a smooth gradient under simple, readable rules.

The work centers on making the puzzle logic deterministic and the interaction responsive, while keeping the UI clear on a wide range of screen sizes.

I worked as a Unity developer, implementing the core puzzle loop and the supporting systems needed for stable Android shipping.

What I Worked On

  • Implemented the gradient-matching puzzle rules and win/validation logic.
  • Built touch-driven tile interactions and responsive UI behavior for common mobile layouts.
  • Kept puzzle parameters data-driven so tuning and iteration didn’t require risky code changes.
  • Added session flow and progression hooks to support short-play loops and iterative difficulty adjustments.
  • Profiled and optimized the interaction loop to minimize jitter and avoidable GC allocations.
  • Maintained Android build/release readiness (packaging, device validation, and store-ready output).

Technical Notes

  • Designed color ordering/comparison to be deterministic and easy to reason about, avoiding device-specific edge cases.
  • Kept input and drag logic allocation-free in hot paths to maintain stable frame pacing.
  • Separated puzzle state from UI so presentation changes didn’t destabilize rule evaluation.
  • Validated interaction thresholds across common resolutions to keep the game playable on smaller screens.

Outcome / Impact

  • Shipped to production on Google Play.
  • Delivered a stable, responsive puzzle loop suitable for quick mobile sessions.
  • Improved iteration speed by keeping key tuning knobs data-driven and isolated from core logic.
