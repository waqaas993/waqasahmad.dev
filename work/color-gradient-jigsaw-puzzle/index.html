Color Gradient Jigsaw Puzzle

A jigsaw puzzle experience where pieces blend into a complete color gradient.

Overview

Color Gradient Jigsaw Puzzle is a mobile jigsaw experience where the “image” is a smooth color gradient rather than a traditional picture.

The core challenge is making piece interaction feel crisp and forgiving on touch while keeping the underlying color ordering consistent as the puzzle scales.

I worked as a Unity developer, focusing on the puzzle interaction layer, data-driven puzzle setup, and the performance/stability constraints that come with lots of interactive pieces.

What I Worked On

  • Implemented touch-first jigsaw interactions (drag, snap-to-target, placement validation) with clear feedback.
  • Built the logic for gradient-driven puzzles so piece ordering and “correctness” stay deterministic across devices.
  • Added quality-of-life UX around selection, snapping thresholds, and error tolerance so the puzzle feels smooth instead of finicky.
  • Implemented save/resume for in-progress puzzles so sessions can be short and interruptible.
  • Profiled and optimized for many active pieces on screen, reducing per-frame work and avoidable allocations.
  • Maintained Android build/release readiness (packaging, device validation, and store-ready output).

Technical Notes

  • Handled input and coordinate-space conversions carefully to keep interactions consistent across aspect ratios and DPI ranges.
  • Tuned snapping and placement checks to be forgiving while still preventing incorrect “near misses” from locking in.
  • Focused on predictable frame pacing by keeping hot-path code allocation-free and avoiding excessive per-piece updates.
  • Separated puzzle rule evaluation from presentation so UI polish and logic changes could evolve independently.

Outcome / Impact

  • Shipped to production on Google Play.
  • Delivered stable, touch-friendly jigsaw interactions suitable for quick sessions.
  • Improved maintainability by keeping puzzle rules, data, and presentation cleanly separated.
