Idle Flight Manager

A live-world airline management game built with React, TypeScript, Vite, and Capacitor. I’m one of its core engineers, working across player data, monetization, platform, and release.

Google Play App Store

Overview

Idle Flight Manager is an airline management game where players build multi-stop routes on a live world map, watch planes fly them in real time, unlock regions from US states to whole countries, and climb ten aircraft tiers. Random events, daily missions, seasonal events, NPC traffic, and offline earnings keep the network alive between sessions. The project is a good example of my shift from Unity-only work into modern web-to-mobile product development.

Tech stack

React 19, TypeScript, Vite, Tailwind, Zustand, and Leaflet with offline map tiles, wrapped with Capacitor and custom native plugins. Supabase for cloud save and leaderboards; Firebase Analytics, Crashlytics, and Remote Config; devtodev for analytics, A/B tests, and push; AppsFlyer; AppLovin MAX; native IAP. Vitest, Playwright, Storybook, and Fastlane with a shared build pipeline.

What I focused on

I led cross-device cloud save (single device, transfer codes, then shared account sync with reinstall recovery) and built weekly leaderboards with level-band leagues and a profanity filter. I also hardened IAP and revenue integrity (purchase races, receipt spoofing, attribution), tuned ad waterfalls and cadence, set up stable A/B segmentation and segmented push, profiled map rendering, kept up with iOS and Android platform changes, built e2e and on-device debug harnesses, and shipped a steady stream of store releases.

Why it matters

This project shows my current operating style: hands-on engineering paired with AI-assisted development. I started with Cursor and moved the team’s rules, commands, and skills over to Claude Code. I keep iteration speed high and use instrumentation and production feedback to guide what gets built next.
