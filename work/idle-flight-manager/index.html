Idle Flight Manager

A live-world airline management game built with React, TypeScript, Vite, and Capacitor, using Cursor-heavy workflows for fast product iteration.

Google Play App Store

Overview

Idle Flight Manager is an airline management game where players create routes, assign aircraft, unlock regions, and grow an always-running aviation network. The project is a good example of my shift from Unity-only work into modern web-to-mobile product development.

Tech stack

The product is being developed with React, TypeScript, Vite, Capacitor, and mobile build pipelines, with Cursor used heavily for implementation planning, code iteration, debugging, and instrumentation.

What I focused on

The work involves product systems rather than isolated UI: route creation, map-driven interactions, progression, balancing surfaces, mobile packaging, store delivery, and the debugging workflows needed to keep a cross-platform product moving quickly.

Why it matters

This project shows my current operating style: combine hands-on engineering with AI-assisted development, keep iteration speed high, and use instrumentation and production feedback to guide what gets built next.
