Idle Truck Fleet

An idle trucking game about building America’s largest fleet. My main contribution was bringing a production-grade cloud save system over from Idle Flight Manager and making it safe for this game’s economy.

Overview

Players buy trucks, hire drivers, and dispatch them on coast-to-coast jobs, with an AI manager, repairs, incidents, R&D, contracts, and offline catch-up. The game is vanilla TypeScript with a Canvas 2D world and DOM UI, shipped with Capacitor.

What I built

The cloud save port: Supabase schema and migrations, durable device identity, sync orchestration, restore prompt and conflict resolution, transfer codes and unlinking, ledger merge with payout guards, IAP refund revocation, and protection against idle devices creating needless revisions. I also isolated e2e runs from production data and shipped a round of UX and A/B-flagged fixes.

Tech stack

TypeScript, Vite, Canvas 2D, Capacitor 8, Supabase, Firebase, native IAP, AppLovin, i18next across 11 locales, Vitest, Playwright, Storybook, and Fastlane.

Why it matters

Reusing a hard-won system across products is where engineering effort compounds. Porting it meant adapting identity, economy, and purchase rules to a different codebase without breaking existing players.
