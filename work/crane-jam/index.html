Crane Jam

A 3D puzzle game where you tap cargo out of a tangled yard and a magnetic crane delivers it to the matching truck. I’m building it solo; it started as a one-to-two-day feel prototype.

In active development

Overview

Only one truck accepts cargo at a time; everything else waits on limited holding pads, and a full yard means you’re jammed. Fragile, locked, chained, heavy, and mystery cargo add rules, and boosters (Undo, Hint, Clear Path, +1 Slot) give players a way out.

What I’m building

Beyond the core feel, I built the commercial foundations: a 46-level campaign grouped into yards with checkpoints, a daily challenge, a Master Yard, coins and shop, streaks, rewarded-ad placements, analytics hooks, a wordless tutorial, and a filming mode for marketing capture.

Level design tooling

The interesting part is content. Levels are a dependency graph rather than a physics sim, so I built a level factory, validator, and economy reports, a difficulty model over the state space, a measure of whether a level actually “asks for thought,” a Hint that only suggests moves that can still win, and a prototype generator that works backwards from the solution to build conflict in.

Tech stack

TypeScript, React 19, three.js via React Three Fiber and drei, Framer Motion, Tailwind, Vite, Capacitor for Android, and Node tooling scripts for level generation and validation.
